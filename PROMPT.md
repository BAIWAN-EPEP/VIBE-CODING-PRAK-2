Halo! Saya ingin meminta bantuanmu untuk mengembangkan proyek aplikasi web kelompok kami sebelumnya menjadi arsitektur berbasis microservice. Berikut adalah ketentuan dan detail tugas yang harus kita ikuti:

1. KELOMPOK & PROYEK:
- Kembangkan proyek yang sudah ada (jangan buat dari awal/baru).
- Gunakan kembali User Story dan Acceptance Criteria dari proyek sebelumnya.

2. KETENTUAN ARSITEKTUR & TEKNOLOGI:
- Ubah/pecah arsitektur proyek menjadi minimal 2 (dua) service/microservice yang terpisah.
- Setiap service harus memiliki fungsi dan tanggung jawab yang jelas.
- Antarservice wajib dapat saling berkomunikasi menggunakan API (misalnya REST API atau HTTP/gRPC).
- Teknologi yang digunakan bebas dikembangkan, disesuaikan, atau diubah sesuai kebutuhan microservice.

3. ALUR FITUR UTAMA:
- Pastikan minimal ada 1 (satu) alur fitur end-to-end yang berjalan dengan sukses dengan melibatkan kolaborasi antar service yang dibuat.

4. BANTUAN AI CODING:
- Bertindaklah sebagai AI Coding Assistant untuk membantu proses perancangan, pembuatan kode, konfigurasi komunikasi API, hingga pembuatan dokumentasi (README dan dokumentasi penggunaan AI).

TUGAS UNTUKMU SAAT INI:
Silakan bantu saya merancang langkah-langkah awal pengembangan ini, meliputi:
1. Usulan pemecahan service (minimal 2 service) berdasarkan arsitektur web standar.
2. Rancangan komunikasi API antarservice tersebut.
3. Struktur folder atau boilerplate kode dasar untuk memulai pemisahan service ini.

(Catatan: Berikan penjelasan dalam Bahasa Indonesia yang jelas, terstruktur, dan mudah dipahami agar saya bisa memeriksa serta memperbaiki kodenya nanti sesuai ketentuan.)
